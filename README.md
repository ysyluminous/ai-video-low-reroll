# ai-video-low-reroll

一套把 AI 短视频「废片率」压下来的操作流程，写成一个可以直接给 AI 助手加载的 skill。

> **来源**：本 skill 的所有方法均来自 Eian（@EianLu）的《Codex+Seedance AI视频：从一个想法到成片的全流程》
> <https://x.com/EianLu/status/2118317430665613741>
> 本仓库只做中文整理与检查清单化，不是原创方法，也不是原文转载。

**核心只有一句：把错误挡在花钱之前。** 文字里能发现的错，别留到图上；图上能发现的错，别留到视频上。

因为成本顺序是 文字 → 图片 → 视频，越往后越贵，所以检查顺序必须反着来。

---

## 它治什么病

AI 视频最贵的不是生成，是重跑。

常见的浪费长这样：

- 故事还没想清楚就开始画首帧，画完发现镜头没法接
- 首帧随便出一张就提交视频，人物多一只手、道具凭空出现
- 提示词里写「不要出现文字」，模型偏要写
- 一条视频有问题，原样再跑一遍，还是同一个错

这套流程就是把这四种钱提前省掉。

## 四件事

| 顺序 | 做什么 | 省的是 |
|---|---|---|
| 1 | 故事定稿前不画图，先避开模型拍不出来的画面 | 整轮返工 |
| 2 | 分镜每镜换角度，且每镜必须写清「什么在动」 | 呆板镜头重拍 |
| 3 | 先画尾帧再改出首帧，两张机位构图锁死 | 视频里慢慢变形 |
| 4 | 七段式提示词 + 提交前逐项审核 | 最贵的那一次重跑 |

## 怎么用

**任意 AI 助手（Claude / ChatGPT / Codex / 其他）**

把 `SKILL.md` 全文贴进对话，或放进项目的自定义指令里，然后正常提需求。它会在写分镜和写提示词时按这套流程走。

**支持 skill 目录的 agent**

把整个文件夹放进 skills 目录即可，`SKILL.md` 的 frontmatter 已经是标准格式。

**自己看**

`SKILL.md` 一页，直接读。`references/model-failure-table.md` 是随查随用的对照表。

## 出处

本 skill 的所有方法、规则与判断标准，全部来自 **Eian（@EianLu）** 的《Codex+Seedance AI视频：从一个想法到成片的全流程》：
<https://x.com/EianLu/status/2118317430665613741>

本仓库是这篇方法的中文操作化整理：删掉了原文里 Codex / Seedance 的账号与接口细节，把散在各节的规则收成可直接执行的检查清单，并补了七段式提示词模板和审核话术。没有任何一条规则是仓库作者自己发明的。

**这不是原文转载，也不替代原文。** 想看完整推演过程（工具分工、四线程工作模式、每一处踩过的坑），请读原文。

## 不做什么

- 不提供任何模型接口、代理或额度
- 不承诺出片效果，模型能力会变，规则需要自己校准
- 不包含原文的授权内容
