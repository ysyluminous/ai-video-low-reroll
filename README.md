**把 AI 短视频的废片率压到最低的操作流程 —— 一个可直接加载的 skill。**

> 成本顺序是 **文字 → 图片 → 视频**。越往后越贵，所以检查顺序必须反着来。
> 文字里能发现的错，不留到图上；图上能发现的错，不留到视频上。

## 它治什么病

AI 视频最贵的不是生成，是重跑。一条 720p 的 5 秒镜头按秒计费，重拍三次就是三倍的钱，而其中大部分错误本来在免费环节就能发现。

| 常见浪费 | 本 skill 的拦法 |
|---|---|
| 故事没想清楚就画首帧，画完发现接不上 | 故事定稿前不画任何图 |
| 首帧随便出一张就提交，人物多一只手 | 首尾帧 8 条放大检查 + 提交前独立审核 |
| 提示词写「不要出现文字」，模型偏要写 | 改成正面的「画面里一直只有这几个人」 |
| 一条视频有问题，原样再跑一遍 | 先剪 / 代码修 / 改提示词后再重拍，且只拍这一镜 |
| 云、月亮长出五官 | 用「蓬松灰白积云，只有棉絮纹理」这类物理描述 |

## 流水线

```
想法
 │
 ├─ 1 故事   片段式结构 · 5 条标准 · 配歌对拍 · 盲审 ──────── 免费
 ├─ 2 分镜   9 项字段 · 每镜换角度 · 38%/62% · 独立配色 ───── 免费
 ├─ 3 画风   参考图 → 设定图（正/侧/表情，固定特征写死位置）── 便宜
 ├─ 4 首尾帧 先写后画 → 先尾后首 → 16:9 对齐 → 8 条检查 ───── 便宜
 ├─ 5 提示词 七段式，逐秒写清，正面写法 ──────────────────── 免费
 ├─ 6 审核   另开 agent 只挑错，写「通过」才报价 ─────────── 免费
 ├─ 7 生成   720p 草稿 → 先试最难镜 → 按秒付费 ───────────── 最贵
 ├─ 8 后期   代码转场 · 只调彩度亮度 · BT.601→709 · lanczos ─
 └─ 9 复核   盲看成片 · 硬伤/小问题分列 · 经验沉淀
```

**三道钱包闸门**：画正式镜头前确认画风 → 批量出图前报张数 → 提交视频前审核通过并报价。

## 安装

支持任何能读 `SKILL.md` 的 agent（Claude Code / Codex / Cursor / OpenCode / Gemini CLI 等）。

```bash
# 方式一：skills CLI
npx skills add ysyluminous/ai-video-low-reroll

# 方式二：手动放进 skills 目录
git clone https://github.com/ysyluminous/ai-video-low-reroll.git \
  ~/.claude/skills/ai-video-low-reroll
```

**方式三：不装也能用。** 把 `SKILL.md` 全文贴进对话，需要时再贴 `references/prompts.md` 里的对应提示词。

## 30 秒上手

对 agent 说：

```
我想做一支 20 秒短片：深夜便利店，店员给只买一颗糖的老人免单，
老人走后，店员发现柜台多了一张旧照片。
```

它会先问你片长、画幅、预算、要不要配乐和字幕，然后依次交付：

| 产物 | 来自 |
|---|---|
| 逐镜头故事 + 5 条标准自查 | `SKILL.md` §2 |
| 9 字段分镜表 + 色表 | §3 + `prompts.md#分镜` |
| 画风、设定图提示词 | §4 |
| 每镜首帧/尾帧描述，过审后才画 | §5 |
| 七段式视频提示词 | §6 |
| 提交前审核结论（通过/不通过） | §7 + `prompts.md#提交前审核` |
| 720p 草稿与花费预估 | §8 |
| 后期脚本与成片复核清单 | §9–10 |

## 常见问题

**这套流程只适用于 Seedance 吗？**
不是。成本阶梯和审核顺序对任何「图生视频」模型都成立；`tool-setup.md` 里的型号和价格只是原文的参考值。

**一定要开子 agent 吗？**
不一定。开不了就自己当第二双眼睛，按 §7 的 5 项核对，只是更容易漏。

**为什么非要先画尾帧？**
尾帧信息最多。先画它，再在它上面改出首帧，两张的机位和构图天然一致；反过来做，构图一定会漂。

**提示词里写了「不要」为什么不管用？**
扩散模型对否定词不敏感。改成正面的存在描述：「画面里一直只有首帧这几个人」。

**预算很紧怎么办？**
全程 720p + 2.0 mini，先试最难的一镜；修不好再重拍，且重拍前必须先改提示词或首尾帧。
