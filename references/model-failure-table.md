# 模型易犯错对照表与审核清单

> 附录文件，配合 `SKILL.md` 的第 4、6、8 节使用。

## 一、模型最容易犯的错 / 应该怎么写

| 模型容易犯的错 | 应该怎么写 |
|---|---|
| 一群人同时做同一个动作 | 写清谁先谁后：「老爸第一个……过一两秒老奶奶才……小女孩最后……」；首帧也不要摆同一个姿势 |
| 本该风做的事，人自己动手做了 | 写清原因，再写「两只手从头到尾都没有碰它」 |
| 云、月亮、植物长出眼睛和嘴巴 | 不写「卡通云」，写「蓬松的灰白色积云，只有棉絮一样的纹理和阴影」，动作只写怎么移动 |
| 人往反方向走 | 方向按画面写：「朝画面左边走，跨过左边的店门」 |
| 一句话有两种意思 | 写更具体：「左上角石头房子的窗口里」，再加「驾驶座一直空着」 |
| 东西的数量变了 | 把数量直接写出来：「只有一封黄信封」 |
| 写「不要怎么样」不管用 | 改成正面的说法：「画面里一直只有首帧这几个人」 |
| 模型自己联想道具用法 | 干脆不让这个道具出现在有动作的镜头里 |
| 东西凭空出现 | 只用首帧里已经有的东西 |
| 东西突然飞走或瞬移 | 写清它怎么动：「顺着后脑勺往后一滑，接住，扣回头上」 |
| 雨、帽子、纹身拍着拍着没了 | 首帧和尾帧都画上 |
| 一个镜头动作太多就乱 | 每镜只写一两个主要动作 |
| 动作时间和写的不一样 | 时间只算大概，多留 0.5 秒，后期用剪辑和变速对节拍 |
| 镜头推得没写的明显 | 后期用代码再推一点 |
| 人的嘴自己动 | 写明「人物不说话」，还动就用代码修 |
| 写了「没有音乐」还是混进音乐 | 不用片段自带声音，后期另外加 |
| 结尾几帧突然跳到尾帧 | 后期选一张没问题的画面，后面都停在这一张 |
| 第一帧特别锐 | 直接去掉这一帧 |
| 越到后面越暗越冷 | 每条按它自己的首帧把颜色调回来 |

## 二、首尾帧画完要逐条查（放大看）

1. 动作要用到的东西，首帧里必须有（否则会凭空冒出来）
2. 别人的反应要提前摆好：一个镜头内切不出去，首帧里就要安排好位置和朝向
3. 多人不能摆同一个姿势，否则会同时动
4. 给动作留空间：东西要落到的地方、人的头顶都要留白
5. 风往哪边吹要统一，不能围巾往左、床单往右
6. 缩到手机大小看一遍，远处的人太小就改
7. 放大看有没有多余的东西（多一只壶、多一条细线）
8. 首尾帧叠在一起看有没有错位：不该变的地方必须一致，否则视频里会慢慢变色/变大

## 三、提交视频前的审核提示词

```
你是审核，只读不改。这个镜头马上要提交视频生成，花的是真钱。
材料：[提示词]、[首帧]、[尾帧]、[设定图]、[分镜表]、[配色规则]。
逐项核对，放大看图：
1. 提示词的每句话和两张图对得上吗？（位置、左右、颜色、人数、道具数量、衣服、表情）
2. 两张图的机位、大小、背景一致吗？
3. 和设定图、配色规则、前后镜头对得上吗？
4. 动作现实吗？每个动作的原因写了吗？手放在哪？
5. 模型可能在哪里出错？（同时动作、凭空出现、长脸、走反方向、歧义词）
最后只写「通过」或「不通过」。不通过就逐条列出要改什么。
```

## 四、成片复核提示词

```
这是成片：[文件]。你第一次看，我不告诉你任何结论。
1. 全部解码，每镜取多张全分辨率帧，切点前后各取 3 帧。
2. 先写你看懂的故事，再列看不懂的地方。
3. 逐镜查：重复的动作、道具数量、穿帮、突跳、颜色跳变、脸变形、字的问题。
4. 明确写出你查不了的东西（动态手感、声音）。
每条写：时间、帧号、问题。分「硬伤」和「小问题」。
```
